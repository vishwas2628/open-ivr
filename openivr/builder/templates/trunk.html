Carrier Provisioning Guide

    Recommendations

      Authentication Method

      Choose how SIP authentication is performed. Use the method your provider assigns.

      Register-based

      Your PBX sends SIP REGISTER with username/password. Used only by providers that require registration.

      SIP Credentials

      Username/password SIP digest authentication. Typical for Plivo Zentrunk outbound.

      IP Authentication / ACL

      Allow traffic only from the provider's SIP signalling IPs. Common for inbound origination.

      Connection Settings

      SIP registrar endpoint and transport.

      Use UDP over signaling port 5060 unless your provider requires TCP.

      Standard SIP uses 5060 for UDP/TCP and 5061 for TLS.
